# Contactless Doorbell System

## About the Project

This is an Arduino-based contactless doorbell system.

It uses an ultrasonic sensor to detect a person without touching the doorbell.

When a person comes near the sensor, the buzzer rings automatically.

## Components

* Arduino
* Ultrasonic Sensor
* Buzzer
* Breadboard
* Jumper Wires

## Working

1. The ultrasonic sensor detects a person.
2. Arduino measures the distance.
3. If the person is within the set distance, the buzzer turns ON.
4. When the person moves away, the buzzer turns OFF.
